# 🎯 AI Interview Feedback Coach

## 📌 Overview

AI Interview Feedback Coach is a role-based mock interview application that helps users prepare for technical interviews through AI-generated questions and performance feedback.

The application generates interview questions based on the selected role, skills, and difficulty level, then provides a detailed report highlighting strengths, weaknesses, and areas for improvement.

## ✨ Features

* Role-based interview preparation
* Skill-specific question generation
* Multiple difficulty levels
* AI-generated interview reports
* Technical and communication assessment
* Skill-wise performance analysis
* Personalized improvement suggestions

## 🛠️ Tech Stack

* Python
* Streamlit
* LangChain
* Groq API / Gemini API
* Prompt Engineering

## ⚙️ Workflow

1. Select a role.
2. Choose relevant skills.
3. Select interview difficulty.
4. Answer AI-generated interview questions.
5. Generate the final interview report.
6. Review performance and improvement areas.
